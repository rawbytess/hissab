# Exchange Rates<sup className={"glow text-lg mx-2"}>PRO</sup>

You can convert currencies using the latest exchange rates. The rates are cached for 12 hours, so they are not realtime rates,
but we plan to shorten the cached duration overtime.

The syntax is similar to unit conversion.

> \{value} \{source currency} to \{destination currency}

You can use currency symbols but must use the ISO 3-letter currency code.
Also similar to unit conversion, you can seamlessly perform calculations with values of different currencies and all necessary conversions will take place automatically.

  text={`$33 usd to eur\n$40 usd + 15 cad + 300 cny`}
