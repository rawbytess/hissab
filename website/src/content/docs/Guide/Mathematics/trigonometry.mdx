# Trigonometry

#### Hissab supports following trigonometric operations:

### Basic functions

You can enter angles in any units. Default is degrees.

<HissabExample
  text={`sin 60\ncos 60\ncot 13 radians\ncsc 23 arcminute 40 arcsecond`}
  classes="hissab-example"
/>

### Arc functions

<HissabExample
  text={`asin 0.12\nacos -0.25 to radians\nacot 123`}
  classes="hissab-example"
/>

### Hyperbolic functions

<HissabExample text={`sinh 6\ncosh 6\ncoth 1.45`} classes="hissab-example" />

### Hyperbolic arc functions

<HissabExample
