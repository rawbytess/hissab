Hissab supports the following binary operations.

| Operator                                          | Example                                                                      |
| ------------------------------------------------- | ---------------------------------------------------------------------------- |
| ~ <blockquote> Bitwise Not </blockquote>          | <HissabExample text={`~0b10101010`} classes="hissab-example"/>               |
| & <blockquote> Bitwise AND </blockquote>          | <HissabExample text={`0b10101010 & 0b11001101`} classes="hissab-example"/>   |
| &#124; <blockquote> Bitwise OR </blockquote>      | <HissabExample text={`0b10101010 \|  0b11001101`} classes="hissab-example"/> |
| xor <blockquote>Bitwise XOR </blockquote>         | <HissabExample text={`0b10101010 xor 0b1100110`} classes="hissab-example"/>  |
| >> <blockquote> Bitwise right shift </blockquote> | <HissabExample text={`0b10101010 >> 3`} classes="hissab-example"/>           |
| \<< <blockquote> Bitwise left shift </blockquote>  | <HissabExample text={`0b10101010 << 3`} classes="hissab-example"/>           |

Binary operations can be performed not just on binary numbers but with
any number system.
