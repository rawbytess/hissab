# AI Agent

Hissab AI Agent allows natural language calculations using the Hissab Math engine directly in your application.
The AI Agent uses custom fine tuned LLMs to provide the best performance and accuracy for math operations.

## AI Agent vs MCP Server
AI Agent uses custom fine tuned LLMs to provide the best performance and accuracy for math operations.
While MCP Server plugs as a tool in any LLM you already use.

```
Your Prompts -> AI Agent -> Results
Your Prompts -> Your LLM + Hissab MCP Server -> Results
```
