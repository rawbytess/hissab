:::caution
Hissab app is also available in the various app stores, but is no longer supported and will not receive any more updates.
Please use the following installation methods to use hissab in your device.
:::

Hissab is a web app and can be easily installed as PWA in most platforms.

## Web

Head over to [app.hissab.io](https://app.hissab.io) to use Hissab on the web.

## Mac OS, Windows & Linux

:::note
You must use Google Chrome or Microsoft Edge or other chromium based browser
