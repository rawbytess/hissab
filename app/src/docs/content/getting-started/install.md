# Install Hissab

Hissab runs as a **web app** and can be installed as a **Progressive Web App**
in modern browsers.

## Web app

Open the app in your browser and use it directly. Your notebooks, provider
settings, MCP servers, and skills are stored **locally in the browser profile**.

## Install as an app

Browsers that support PWAs show an install action in the address bar or browser
menu. Installing creates a standalone app window while keeping the same local
browser storage.

Typical browser actions:

- **Chrome / Edge desktop** — use the install icon in the address bar, or the app install option in the browser menu.
- **Android Chrome** — use the browser menu and choose install / add-to-home-screen.
- **Safari (iOS / iPadOS)** — use Share, then Add to Home Screen.

## Offline behavior

The app shell can be cached by the browser, so **calculations that run locally
keep working** from the installed app.

:::note

AI provider calls, model refreshes, remote MCP servers, and realtime search
require **network access**.

:::

## Updates

The browser updates the installed PWA when a newer app build is available. If a
page looks stale after an update, **reload the app window**.
